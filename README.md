# Carte simplifiée : les coulées de lave du Semeru (5ème)

Support simplifié pour l'étude de cas « Habiter un espace à fort risque volcanique » (classe de 5ème).

## Contenu

- `cartes/carte_semeru_5e.png` — carte simplifiée prête à projeter ou imprimer (3000 × 2120 px)
- `cartes/carte_semeru_5e.svg` — version vectorielle modifiable
- `cartes/carte_originale.png` — carte initiale (Badan Geologi, Indonésie) ayant servi de base

## La carte

- **Titre** : Le Semeru (île de Java, Indonésie) — Les zones menacées par les coulées de lave
- **Communes figurant sur la carte** : Oro-Oro Ombo, Supiturang (district de Pronojiwo) et Penanggal (district de Candipuro)
- **Légende en français** : volcan Semeru (3 676 m), zone de danger très élevée (nuées ardentes, projections, gaz), zone menacée par les coulées de lave et les lahars, terres cultivées et zones habitées, rivière Besuk Kobokan, villages, direction des coulées
- **Éléments cartographiques** : orientation (N), échelle (0 à 8 km), encart de localisation (île de Java)

Source : d'après la carte des risques volcaniques du Semeru (Peta Kawasan Rawan Bencana, Badan Geologi, Indonésie).
